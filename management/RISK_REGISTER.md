# Risk Register

Updated: 2026-09-28

| Risk | Severity | Control |
|---|---|---|
| Agents silently change scientific protocol | Critical | Work Package authority boundary + Decision Records |
| Two coding agents overwrite each other | High | Separate Git branches/worktrees |
| Chat context becomes the only project memory | High | Repository-mediated communication |
| Local implementer draws unsupported scientific conclusions | High | Evidence Package is descriptive; SCI layer interprets |
| Canonical evidence is accidentally rerun/replaced | Critical | Existing AGENTS/finalization restrictions + explicit authorization |
| Reviewer and implementer share the same failure mode | Medium | Independent verifier, preferably different model |
| Negative experiments disappear | High | Preserve failed EPs and rejected WPs |
| Management summaries drift from evidence | High | Summaries must reference durable artifact IDs/paths |
| Agent creates busywork | Medium | No work without substantiated gap + WP |
