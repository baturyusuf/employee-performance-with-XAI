# Management Layer

This directory is the Human PI dashboard for the multi-agent research system.

Read in this order:
1. `EXECUTIVE_SUMMARY.md`
2. `PROJECT_STATUS.md`
3. `CURRENT_PRIORITIES.md`
4. `RISK_REGISTER.md`
5. `DECISION_LOG.md`

Detailed scientific and engineering evidence remains in the existing canonical records and the `agent/` workflow artifacts. Management files summarize; they do not replace evidence.
