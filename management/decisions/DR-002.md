# DR-002 — Scientific and implementation authority separation

Status: ACCEPTED
Owner: Human PI
Date: 2026-09-28

## Decision

GPT-5.6 Sol agents serve as scientific directors/advisors. They perform deep analysis, research planning, methodology design, gap analysis and scientific review, but they do not implement production research code.

Local LLM agents implement approved Work Packages, run code and produce Evidence Packages.

## Consequences

Implementation agents may choose engineering details only where the Work Package leaves scientifically equivalent options. They may not silently change hypotheses, targets, datasets, primary metrics, leakage rules or claim boundaries.
