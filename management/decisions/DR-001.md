# DR-001 — Initial orchestration platform

Status: ACCEPTED
Owner: Human PI
Date: 2026-09-28

## Question

Which platform should host the first version of the multi-agent research organization?

## Decision

Use Zed as the interactive execution surface and GitHub as the durable system of record. AgentPool is explicitly postponed.

## Rationale

The research repository, code, evidence and review history remain visible in one Git-centered workflow while avoiding premature investment in a separate orchestration platform.

## Consequences

Agent-to-agent communication is repository-mediated. Zed threads are not treated as durable shared memory.
