# Decision and Conflict Protocol

## Decision Records

Create `management/decisions/DR-NNN.md` when a decision changes:
- scientific scope,
- dataset inclusion/exclusion,
- target definition,
- feature policy,
- evaluation design,
- primary metrics,
- primary model identity,
- XAI interpretation boundaries,
- manuscript contribution claims,
- publication strategy.

Required fields:

```markdown
# DR-NNN — Decision title
Status: PROPOSED | ACCEPTED | SUPERSEDED
Owner:
Date:

## Question
## Competing options
## Evidence considered
## Decision
## Scientific rationale
## Consequences
## Required follow-up
## Supersedes / superseded by
```

## Conflicts

When two agents disagree, do not resolve by majority vote.

Create a conflict section in the relevant WP/RR:
1. exact conflicting claims,
2. evidence cited by each side,
3. whether the conflict is empirical, methodological or interpretive,
4. experiment/research capable of resolving it,
5. unresolved risk.

SCI-DIRECTOR decides only after the disagreement is explicit. The Human PI remains final authority.
