# Journal Supplementary Materials

This directory is the journal-facing supplement only. Internal reviewer simulations, approval records, revision diffs, development logs, and workflow notes are intentionally excluded.

Included scientific materials:

- `TABLE_S1_FEATURE_AVAILABILITY.md` — complete governed feature/information-policy contract.
- `TABLE_S2_PREPROCESSING_HYPERPARAMETER_SEARCH.md` — preprocessing, estimator settings, candidate grids, and selection rules.
- `TABLE_S3_CV_SEED_CONTRACT.md` — CV, seed, OOF, and reuse/refit contract.
- `TABLE_S4_PER_CLASS_METRICS.md` — classwise precision, recall, F1, and support for the four leading trained systems.
- `CONFUSION_MATRICES.csv` — canonical and selection-objective confusion-matrix evidence.
- `TABLE_S5_PROTOCOL_AUDIT_GATES.md` — reusable protocol/audit gate specification.
- `TABLE_S6_SUBGROUP_UNCERTAINTY.md` — point estimates, eligibility, and exploratory simultaneous intervals for all six prespecified subgroup attributes.
- `SUPPLEMENTARY_EVIDENCE_LEDGER_ROUND2.csv` — versioned manuscript-to-evidence ledger.

Employee-level data, raw datasets, fitted models, fold-level employee records, reviewer simulations, and internal development artifacts are not journal supplementary materials.
