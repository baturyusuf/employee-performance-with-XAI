# Validated-Source Assembly Limitation

The current GitHub connector write path has been used to create the submission-facing finalization documents. Validated legacy source artifacts (S1-S3, confusion matrices, evidence ledger, bibliography) remain referenced by their authoritative original paths and Git blob identities. Their scientific contents are not duplicated by manual retyping in order to avoid accidental drift.

This does not affect the scientific finalization status; it affects only final-folder duplication/packaging. The official MDPI template/PDF production gate remains the controlling submission blocker.
