# Data Availability Statement — Final Draft Pending Rights Sign-Off

## Manuscript-facing draft

Aggregate evidence supporting the reported results, including schemas, content hashes, analysis code, versioned claim-to-source records, and qualified upstream locators, is available in the project repository. Raw employee-level datasets are not included in the submission or supplementary package because the current provenance record does not establish a complete authoritative source-to-byte chain together with redistribution permission. Where access to third-party source data is required for editorial review, availability must follow the applicable source terms and any legal, ethical, or privacy restrictions. A final immutable release identifier and archive DOI may be added only after dataset rights, repository release identity, and author approval are resolved.

## Why this wording is used

- The repository evidence currently treats both datasets as public cross-sectional tables but does **not** treat public availability as proof of authenticity, ownership, reuse permission, or redistribution permission.
- Raw employee-level rows therefore remain outside the journal-facing package.
- MDPI requires a Data Availability Statement and states that data should not be shared where ethical, legal, or privacy issues are present; limitations should be made explicit.

2. Determine whether redistribution of the exact bytes used in the study is permitted.
3. If redistribution is not permitted, retain a third-party/restricted-data statement rather than uploading raw data.
4. Add final immutable repository/archive identifiers only after explicit release approval.
