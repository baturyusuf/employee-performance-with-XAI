# Current MDPI / Information Policy Verification

**Verified:** 2026-09-09 using official MDPI sources.

## LaTeX template

MDPI's official LaTeX page states that the ACS, APA, and Chicago template packages contain `template.tex` plus the `Definitions` directory (class, logos, bibliography styles, and definitions). The most recent official page indexed during this finalization reports the packages as updated **23 June 2026**. The submission package should therefore use the current MDPI package rather than an older repository copy.

## Human data / ethics

MDPI's Research and Publication Ethics policy requires an Institutional Review Board Statement for research involving human subjects or human data. If ethics approval is not required, authors must provide an ethics-committee exemption where available or cite applicable local/national legislation; public availability of human data is not itself an ethics determination. The Informed Consent Statement must be consistent with that basis.

## AI-assisted technology

MDPI requires transparency for generative-AI use beyond ordinary grammar/spellchecking or superficial editing. Use in manuscript generation, study design, data collection, analysis, or interpretation should be disclosed in Methods and acknowledged with the tool/purpose. AI tools cannot be authors, and authors remain responsible for the final content.

## Data availability

MDPI requires a Data Availability Statement for research articles. Current MDPI guidance explicitly allows/requires restrictions to be explained where legal, ethical, privacy, or third-party constraints prevent data sharing; restricted data should not be uploaded merely to satisfy openness expectations.
